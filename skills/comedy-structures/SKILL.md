# Comedy Structures

## Overview

Mel Helitzer's *Comedy Writing Secrets* (2005) teaches the craft of humor through learnable structures and formulas. This skill distills the core techniques into actionable patterns.

**WARNING:** `comedy-writing-secrets.md` consumes ~20,000 tokens. Read it only when writing or editing humorous content.

## When to Use This Skill

Use this skill when adding humor to:

- Marketing copy, social media posts, presentations
- Error messages, UI microcopy, onboarding flows
- Dialogue, scripts, creative writing
- Speeches, talks, pitches that need levity
- Any content where engagement matters

**If you want something to be funnier, use this skill.**

## The THREES Formula

Every joke needs six ingredients (THREES):

| Element | Description |
|---------|-------------|
| **T**arget | Who/what are you making fun of? Must resonate with your audience. |
| **H**ostility | Comedy is criticism. Ridicule upward (authority, celebrities, systems). |
| **R**ealism | Start with truth—audiences must relate before you distort. |
| **E**xaggeration | Stretch the truth like a rubber band—not too far, not too little. |
| **E**motion | Build tension through pacing, pauses, and stakes. |
| **S**urprise | The payoff—hide it until the last possible word. |

## The 13 Comedy Structures

### 1. The Reverse
Contradict expectations in the final words.

**Pattern:** Setup creates one expectation → last words flip it

```
"My boyfriend and I broke up, even though we're still deeply
in love. He wanted to get married and I didn't want him to."
—Rita Rudner
```

**How to write it:**
1. State something that sounds complete
2. Add a contradictory tag that reframes everything

### 2. The Triple (Rule of Three)
Two setups + one surprise = comedy gold.

**Pattern:** Item 1 (normal) + Item 2 (normal) + Item 3 (surprise twist)

```
"I celebrated Thanksgiving in an old-fashioned way. I invited
everyone in my neighborhood to my house, we had an enormous
feast, and then I killed them and took their land."
—Jon Stewart
```

**How to write it:**
1. Two believable items build pattern
2. Third item breaks pattern with surprise
3. Third item should be most extreme

### 3. POW (Play on Words)
Twist familiar phrases, clichés, or double meanings.

**Pattern:** Recognizable expression → unexpected interpretation

```
"My wife made me join a bridge club. I jump off next week."
—Rodney Dangerfield
```

**Types of POW:**
- Double entendres ("I lie three" in golf)
- Cliché twists ("The quickest way to a man's heart is through his chest")
- Homonym plays
- Reforming (altering well-known phrases)

### 4. The Paired Elements
Contrast two things using parallel structure.

**Pattern:** A is to B as C is to D (but C is absurd)

```
"Men should be like Kleenex: soft, strong and disposable."
—Cher
```

**How to write it:**
1. Start with two related concepts
2. Draw unexpected parallel that reframes both

### 5. Exaggeration (Hyperbole)
Stretch realistic premise to absurd extreme.

**Pattern:** True observation → stretched to breaking point

```
"My dad's pants kept creeping up on him. By sixty-five
he was just a pair of pants and a head."
—Jeff Altman
```

**Key rule:** Start realistic, exaggerate logically. Don't just be random.

### 6. Understatement
Say less than expected—the inverse of exaggeration.

**Pattern:** Big situation → minimized response

```
"I have my standards. They may be low, but I have them."
—Bette Midler
```

### 7. The Misdirect
Lead audience one direction, reveal another.

**Pattern:** Setup creates false assumption → reveal true meaning

```
"Can I take your picture in the nude?"
"Absolutely not! You'll have to wear your socks and a tie."
```

### 8. The Simple Truth
State the obvious that nobody says out loud.

**Pattern:** Say what everyone thinks but is too polite to say

```
"If you want to be heard—speak up!
If you want to be appreciated—shut up!"
```

### 9. The Callback
Reference earlier material for compounding laughs.

**Pattern:** Earlier joke/detail → referenced again in new context

**How to write it:**
1. Plant something memorable early
2. Bring it back when audience least expects

### 10. The Build
Stack jokes that escalate toward bigger payoff.

**Pattern:** Small laugh → medium laugh → big laugh

**How to write it:**
1. Start with mild version
2. Escalate intensity
3. End with biggest exaggeration

### 11. The Take-Off
Start with recognizable reference, veer into absurdity.

**Pattern:** Familiar situation → unexpected tangent

```
"Two roads diverged in a wood and I took the road less traveled
by... state troopers."
```

### 12. The Comparison
Unexpected juxtaposition of unlike things.

**Pattern:** Thing A is like Thing B (where B is surprising)

```
"I like Florida; everything is in the eighties: the temperature,
the ages, and the IQs."
—George Carlin
```

### 13. Self-Deprecation
Target yourself—safest form of ridicule.

**Pattern:** Make yourself the butt of the joke

```
"I'm not a good lover, but at least I'm fast."
—Drew Carey
```

## Writing Rules

### Save the Funny Word for Last
The punchline's funniest word must be the final word.

**Wrong:** "He was complimented when the editor called his work sophomoric because he had flunked out of college his freshman year."

**Right:** "He had flunked out of college in his freshman year, so he was complimented whenever anybody called his work sophomoric."

### Cut Ruthlessly
- First draft: write freely
- Second draft: cut every nonessential phrase
- Final draft: cut every nonessential word

**Mantra:** Make every word work.

### Don't Telegraph
Never hint that a joke is coming. No "Here's a funny story..." or setup that reveals the pattern.

### The TEE Test
Every premise needs:
- **T**ruth: Reality-based, genuine
- **E**motion: Stated or implied hostility
- **E**xplicitness: Specific, readily understood
